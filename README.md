# 🎓 Students Marks Predictor — Learn with Honesty, Predict with Purpose

### 📘 About

**Students Marks Predictor** is a simple yet meaningful machine learning project built using Python.
It predicts student performance based on study hours or related variables.

This project was developed as a practice in data science fundamentals — *but also as a reminder that knowledge and accuracy are a trust (amanah), not just numbers on a chart.*

---

### 🎯 Objectives

* To understand the concept of **supervised machine learning** (Linear Regression).
* To apply real-world data in predicting outcomes with transparency and fairness.
* To learn how data can reflect patterns, but never define a person’s true worth.

---

### ⚙️ Tech Stack

* **Python**
* **Pandas, NumPy, Matplotlib, Scikit-learn**
* **Jupyter Notebook / Streamlit (optional for deployment)**

---

### 🧠 How It Works

1. The dataset contains students’ study hours and their marks.
2. A Linear Regression model is trained to learn the relationship.
3. The model predicts the expected marks for new input study hours.
4. Visualization and evaluation (R² score) are shown for understanding.

### 🚀 How to Run

#### 1. Clone this repo

```bash
git clone https://github.com/shahasyraf/student-marks-predictor.git
cd student-marks-predictor
```

#### 2. Install dependencies

```bash
pip install -r requirements.txt
```

#### 3. Run the app (Streamlit)

```bash
streamlit run app.py
```
